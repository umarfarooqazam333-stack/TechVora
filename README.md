TechVora — A professional technology publication

This repository contains a starter scaffold for a modern technology website named TechVora. It was created to provide a fast, accessible, SEO-friendly foundation for a future CMS-driven publication.

What's included:
- index.html — polished homepage scaffold
- category templates in /categories
- article template in /templates
- assets/css/styles.css — responsive, mobile-first CSS
- assets/js/main.js — minimal JS (search toggle, lazy-loading)
- assets/images/logo.svg, favicon.svg
- db/schema.sql — database-ready schema for articles, authors, categories, tags, and settings
- sitemap.xml and robots.txt

How to use:
- Open index.html in a static web server or host via GitHub Pages
- Replace placeholder content with original articles and images
- Integrate with a CMS or static site generator later (Hugo, Jekyll, Next.js, etc.)
